## 本仓结构

**一个完整项目**：上游 ZCode fork + 自托管改造 + 手机壳 + relay + 部署件 + 文档，全部在本仓内。

| 目录 | 内容 |
|---|---|
| `packages/` | 上游 ZCode v3.14.3 fork + 自托管改动（设备凭据鉴权、移动端适配、软重连等） |
| `apps/` | 上游 CLI 应用 |
| `mobile/` | Android APK 壳（WebView 容器 + 设备凭据配对 + 前台服务保活）；`mobile/handoff/` 为壳与服务端的协议规格 |
| `relay/` | 远控 relay（官方远控页镜像伺服 + 一次性门票模式） |
| `deploy/` | 部署模板：systemd unit、nginx 配置、部署脚本、管理 CLI（**含占位符，使用前替换**） |
| `e2e/` | 端到端验证脚本 |
| `docs/` | 架构、部署、开发文档，以及需求与计划（见 `docs/README.md`） |

**部署件**：`relay/` 与 `deploy/` 面向具体部署环境，使用前按自己的环境核对。
**敏感边界**：keystore 与密码不入仓；磁盘上的设备凭据只保存摘要。
